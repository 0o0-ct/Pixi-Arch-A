## 🌟 Preámbulo de nuestra Libertad

La Licencia Pública General de GNU (GPL) es una licencia libre con copyleft diseñada específicamente para garantizar tu libertad para compartir, modificar y utilizar el software.

A diferencia de las licencias de software propietario que están diseñadas para quitarte tus libertades de uso y modificación, la GPL tiene como objetivo garantizar que todos los usuarios de **Pixi-Arch-A** tengan las siguientes libertades fundamentales:

1. 🚀 **Libertad de Uso:** Tienes el derecho absoluto de ejecutar el programa para cualquier propósito que desees.
2. 📖 **Libertad de Estudio:** Puedes examinar cómo funciona el código fuente y modificarlo para que haga lo que tú necesites.
3. 🤝 **Libertad de Compartir:** Puedes copiar y distribuir copias del software de forma gratuita o comercial.
4. 🛠️ **Libertad de Mejora:** Puedes publicar tus modificaciones y mejoras para que toda la comunidad se beneficie de ellas.

## 📜 Resumen de los Términos y Derechos

### 1. Código Fuente Abierto
Cualquier persona que distribuya copias de este sistema (con o sin modificaciones) debe poner a disposición del público el **código fuente completo**. Esto asegura que las libertades se transmitan de generación en generación.

### 2. Copyleft Activo
Si modificas este software o utilizas partes del código en un nuevo programa, tu obra derivada **debe ser licenciada también bajo los mismos términos de la GPLv3**. No puedes cerrar el código ni convertirlo en software de pago restrictivo.

### 3. Sin Garantía (AS-IS)
Este sistema se distribuye de buena fe con la esperanza de que sea útil para la comunidad, pero **SIN NINGUNA GARANTÍA** explícita o implícita de comerciabilidad o idoneidad para un propósito particular. El uso del sistema corre bajo tu propia responsabilidad.

### 4. Patentes de Software
La licencia prohíbe explícitamente a cualquier colaborador reclamar regalías o imponer restricciones de patentes sobre el código. Si alguien distribuye el software, te otorga automáticamente una licencia de patentes libre de regalías sobre el código correspondiente.
