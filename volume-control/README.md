# Control de Volumen - Pixi-Arch-A

Control independiente de volumen en Rust + Iced. Se puede ejecutar manualmente como `volume-control`; el atajo `SUPER + V` está reservado para QuickShell.

## Instalar

Desde la raíz del repositorio ejecuta `./install-volume-control.sh`.

## Opciones CLI

- `volume-control --get`
- `volume-control --inc` / `--dec`
- `volume-control --toggle`

Los atajos multimedia de volumen permanecen en `Hyprland-Dots/config/hypr/lua/keybinds.lua`.
